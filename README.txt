AIChatbotPlugin 🤖
Bring artificial intelligence directly into your Minecraft server!
AIChatbotPlugin is a Minecraft plugin that adds AI-powered chat and image generation features to your server.
✨ Features
  💬 AI Chat – `/ai`
- Chat with an AI directly in Minecraft.
- Ask questions and get helpful answers.
- Easy to use with a simple command.

Usage:
/ai <your message>

Example:
/ai How do I build a house in Minecraft?

🎨 AI Image Generation – /aimap

- Generate AI images from text prompts.
- Receive your generated image as a Minecraft map.
- Turn your ideas into images inside Minecraft.

Usage:
/aimap <your image prompt>

Example:
/aimap a futuristic Minecraft castle at sunset

⚙️ Requirements

- A compatible Minecraft server running Paper or a compatible server software.
- The Java version required by your server and plugin.
- A Groq API key for AI chat.
- A Cloudflare account and API token for AI image generation.

Some features may require additional API configuration.

Installation

1. Download the plugin JAR file.
2. Place the JAR file in your server's `plugins` folder.
3. Start or restart your Minecraft server.
4. Open the generated plugin configuration file.
5. Configure your API credentials.
6. Restart the server and test the commands.

 🔑 Configuration & Security

- Keep your API keys and tokens private.
- Never publish API credentials on GitHub.
- Do not share your configuration file if it contains secret credentials.
- If a key or token becomes public, revoke it and generate a replacement.

 🛠️ Troubleshooting

The commands are unknown

- Check that the plugin is installed correctly.
- Make sure the server has been restarted.
- Check the server console for plugin errors.

The AI is unavailable

- Check your API configuration.
- Make sure your API account and credentials are working.
- Review the server console for error messages.

Image generation fails

- Check your Cloudflare configuration.
- Make sure image generation is enabled.
- Check the server console for additional details.
